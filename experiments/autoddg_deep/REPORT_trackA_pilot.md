# Track A pilot 统计报告

## 方法

对 `trackA/{B0,C,Cprime,A}__r1.json` 的 17 张 held-out 表逐表阅读 UFD；依据冻结清单（N_core=68、N_caveat=17，SHA256 前缀 `7b6c8b11`）逐条标记 caveat 是否“陈述且正确”，并标记 core 是否正确保留。统计单位为表；核心保留数为原子断言命中数。两臂差值按 17 张表重采样、10,000 次 bootstrap，报告 percentile 95% CI。T=0，只有一次重复（r1），不是 r1/r2 平均。

## 四臂结果

| 臂 | caveat 正确 | core 保留 | 清单外具体断言 |
|---|---:|---:|---:|
| B0 | 1/17 (5.9%) | 47/68 | 32 |
| C | 0/17 (0.0%) | 50/68 | 31 |
| C′ | 0/17 (0.0%) | 43/68 | 30 |
| A | 0/17 (0.0%) | 48/68 | 33 |

“正确”要求同时覆盖清单中的限定语及其关键条件；只写“有缺失”但未说明会造成何种误读，或只写 caveat 的一部分，计为不正确。清单外具体断言按 UFD 中可核验的具体数值、范围、唯一值、时间/空间范围或数据质量断言计数；泛化用途句不计入。

## 非劣效与 H1

核心事实保留率的 bootstrap 结果：

| 对比 | Δ 均值 | 95% bootstrap CI | 下界 ≥ −0.10 |
|---|---:|---:|---|
| A − C′ | +0.0735 | [−0.0294, +0.1765] | 是 |
| A − C | −0.0294 | [−0.1324, +0.0735] | 否 |

因此 A 相对 C′ 达到核心事实非劣效，但相对 C 未达到冻结的非劣效门槛。

按 brief v3 的 H1 口径：H1b（C′−C 的 caveat 送达）未支持/未定；区间跨越实质性无作用区间，不能声称“预留无作用”。A−C′ 的 caveat 正确率没有正向增益，H1c 未支持；同时 A−C 未通过核心非劣效门槛。H1c 不应写成“无差异”，而是“未支持”。

## 挤掉案例

相对 C′，A 在 `2a3cc123-f9f6-4e1d-a03f-3e33056e5021` 的 UFD 保留了年龄组、race/Hispanic-origin、年份和 birth-rate 主体事实，但没有恢复清单要求的“不能跨年龄组与 race/origin 直接比较”限定；相对 C′ 的核心净差为正主要来自其他表，不能解释为该表 caveat 的质量提升。另一个明显的被挤掉项是 `7b64babd-8c66-4dcb-9be7-6bcd2ef35e04` 的“美国总计行不是州”限定：A/C′ 均未正确陈述。

## 成本

本次落盘结果含 68 条记录、每条 UFD+SFD 一次，即 136 次 gpt-4o-mini 调用；没有账单 usage 元数据。按 prompt/output 字符约 4 字符/token 折算：输入约 332,312 tokens、输出约 59,928 tokens（以 JSON 字符数折算），按 gpt-4o-mini 输入 $0.15/M、输出 $0.60/M，估算约 **$0.086**（未计共享缓存折扣；以官方当前价格为准）。

## 限制

样本为 n=17 表、T=0 单次重复，bootstrap 功效低；profile 使用 5 万行采样；UFD 由模型生成。清单与判定均由 Codex 完成，判定者不是独立人工金标准，且本报告未有所有者 ≥20% 子样本复核与 κ，因此结果应视为探索性证据。四臂之间的 r1 生成噪声也无法由重复平均消除。
